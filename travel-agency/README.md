# Wanderlust Journeys

A responsive, fictional travel-agency landing page built with HTML5, CSS3 and Bootstrap 5.3.3 for the GOMYCODE Bootstrap Components checkpoint.

## Run locally

Open `index.html` in a browser. The page uses Bootstrap, Bootstrap Icons, Google Fonts and Unsplash images from CDNs, so an internet connection is needed for those assets.

## Bootstrap components demonstrated

- Responsive, collapsible navbar
- Bootstrap grid (`container`, `row`, responsive `col-*` classes)
- Native Bootstrap `.card` components inside a responsive Bootstrap grid
- Accordion tour packages
- Form controls, select, validation feedback and alert
- Responsive utility classes and Bootstrap Icons

## Project notes

The contact form demonstrates client-side validation and a success message only. It does not send or store enquiries. The agency, destinations, contact details and tour descriptions are fictional sample content.
